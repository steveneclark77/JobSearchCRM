# JobSearchCRM
CRM-like features for job search

Initial prompt: build a job search tool that helps me track my contacts, opportunities, applications, follow-ups, and to-do items.  a contact might be a person at an opportunity, or a recruiter, or someone I network with about my job search.  an opportunity is a position at a company.  each opportunity came from some source, such as a contact or a job search site such as linkedin or wellfound.  each application has a workflow that moves from lead to research to submit to follow-up to (interview | rejection | pending).  After submit, I should follow up the next business day, then again 3 business days later. Use industry knowledge about the job search process to suggest improvements with a bias towards keeping the application simple.  ask me clarifying questions before you start to build the app.  this app is only for my personal use initially, but may be made available to others in the future.  I need the ability to back up the data, and restore the data in case of database corruption.  there should be a search feature for finding each data type.  contacts include first name, last name, email address, company.  I should be able to log each interaction with a contact.  each opportunity is linked to a contact.
